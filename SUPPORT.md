# Support

## Before opening an issue

1. Use the newest published LogiMate alpha build.
2. Open **Diagnose → Probleme** and resolve any blocking device/output error first.
3. Reproduce the issue once with other wheel-control tools closed.
4. Export only the relevant **redacted** diagnostic information.

Use the Bug Report template for software problems and the Hardware Compatibility template for physical G25/G27/Driving Force GT validation.

Security vulnerabilities must not be reported in normal issues; use GitHub Private vulnerability reporting.
