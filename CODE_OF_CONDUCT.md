# Code of Conduct

LogiMate follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, focus criticism on code and behavior, and do not publish private diagnostics, credentials or personal information. Maintainers may remove abusive, unsafe or privacy-invasive content.

For moderation concerns, use the maintainer contact path documented in the repository rather than escalating personal disputes in issue threads.
