# Audit 51–60 — LogiMate 0.1.6-alpha

This batch begins the native force-feedback engine without pretending that LogiMate already replaces every game-FFB path. All motor output remains Experimental and OFF by default.

51. **Per-wheel FFB safety profile** — persist master gain, bounded constant-force ceiling, future spring/damper/friction gains, slew rate and watchdog by stable physical wheel ID using atomic writes.
52. **Bounded constant-force protocol** — implement classic Logitech slot-0 start/update/stop reports with a hard public ±10% test ceiling.
53. **Serialized FFB worker / one HID owner** — one short-lived worker owns one HID handle for a test session and sends updates on a 20 ms cadence instead of reopening the device every frame.
54. **Master gain + hard force clamp** — master gain can only reduce the requested force; config normalization can never raise the constant-force ceiling above ±10%.
55. **Slew/rate limiter** — force cannot jump directly from zero to target; it moves in clamped 1–5 percentage-point steps per 20 ms tick.
56. **Heartbeat + watchdog** — active FFB sessions publish heartbeats and automatically stop inside a hard 500–2000 ms watchdog window.
57. **Spring / damper / friction protocol foundation** — pure builders for lg4ff condition packets (`0x0b`, `0x0c`, `0x0e`) plus slot-stop reports are compile-tested. They remain hidden from persistent/game output until physical hardware validation.
58. **Single-owner interlock** — the existing selected-wheel/model/PnP/native-PID/Generic-HID gate remains mandatory. OpenG27 blocks LogiMate output before start and is checked again while a test is alive.
59. **Zero-force ownership handoff** — active force is stopped on Emergency Stop, app shutdown, Native Output disable, OpenG27 launch, selected-wheel change, detection reset and `WM_DEVICECHANGE` before device identity is rebuilt.
60. **Native FFB diagnostics** — UI/support report expose effect, requested/applied force, frame count, slew-limit count, heartbeat, watchdog/emergency stops, safety config and last error.

## Release boundary

- Constant-force output is only a short bounded hardware test.
- Spring/damper/friction builders are protocol foundations, not a production FFB promise.
- No game profile, telemetry adapter or universal DirectInput bridge is enabled in this batch.
- Real G25/DFGT/G27 output hardware validation is still required before any Experimental label can be removed.
