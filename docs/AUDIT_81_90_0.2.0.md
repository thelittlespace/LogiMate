# Audit 81–90 — Telemetry Framework — LogiMate 0.2.0-alpha

81. Adapter-neutral normalized `TelemetryFrame`.
82. Local-only UDP JSON telemetry hub bound to 127.0.0.1.
83. Packet-size, JSON and numeric validation with force clamping.
84. Telemetry becomes stale after 750 ms without a valid frame.
85. Deterministic RPM-to-G27-LED mapping.
86. Telemetry force resolves to zero unless physics is running and the player is in control.
87. Bounded 256-frame in-memory telemetry ring buffer.
88. Telemetry adapter registry separates protocol identity from profiles.
89. Game profiles can bind to a telemetry adapter without hard-wiring a game into the engine.
90. Telemetry state, errors and preview values are exposed in UI and diagnostics.
