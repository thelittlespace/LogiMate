# Audit 61–70 — LogiMate 0.1.7-alpha

This batch turns the 0.1.6 bounded FFB worker into a small effect manager while preserving the Experimental safety boundary. Persistent game-driven FFB is still not enabled.

61. **Dedicated four-slot effect manager** — classic effect slots are assigned deterministically: Constant=0, Spring=1, Damper=2, Friction=3. Start/update/stop opcodes are generated per slot.
62. **Bounded Spring hardware test** — Spring can be exercised through slot 1 only after the strict selected-wheel/model/PnP/Generic-HID/OpenG27 gate and remains watchdog-limited.
63. **Bounded Damper hardware test** — Damper uses independent slot 2 and the same short-session ownership/safety rules.
64. **Bounded Friction hardware test** — Friction uses independent slot 3 and the same short-session ownership/safety rules.
65. **Deterministic force mixer** — effect requests pass through effect gain → engine-profile master → safety-profile master → hard per-effect ceiling in a pure/testable stage before packet construction.
66. **Clipping observability** — mixer clamps increment a clip counter and the applied four-channel state is exposed in UI/diagnostics instead of silently hiding saturation.
67. **Per-wheel Wheel-Engine profiles** — Gentle/Balanced/Direct built-ins plus a Custom profile persist rotation and effect-character gains by stable physical wheel ID, separate from hard safety limits.
68. **Transactional profile activation** — applying a profile stops any FFB worker, sends only the requested rotation command, and persists the active profile only after the hardware write succeeds. It never starts motor force by itself.
69. **Generation-safe session ownership** — every FFB worker has a monotonically increasing generation token. Cancellation/effect handoff invalidates the old generation so a stale goroutine cannot overwrite the status of a new owner.
70. **Four-slot stop + dry-run diagnostics** — Emergency Stop clears slots 0–3; Engine Dry Run validates mixer, four packet builders and stop packets without moving the motor. Diagnostics include active profile, generation, all applied channels, clip count and effect-transition count.

## Release boundary

- Native Wheel Output remains Experimental and OFF by default.
- Spring/Damper/Friction are short hardware tests, not persistent game effects.
- Real G25/DFGT/G27 output validation is still required before increasing limits or removing Experimental labels.
- No universal DirectInput/game FFB bridge is enabled in this batch.
